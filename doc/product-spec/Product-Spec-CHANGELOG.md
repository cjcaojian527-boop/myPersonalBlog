# 产品变更记录 (Changelog)

本文档记录产品需求文档的所有变更历史，遵循语义化版本规范（Semantic Versioning）。

## 1.0.0 - 2026-05-11

### 变更类型：新增

### 新增功能
- 文章列表与详情：博客核心浏览功能，支持 Markdown 渲染、代码高亮、封面图、分页、排序
- 搜索：全站搜索（标题+正文+标签），Enter 键触发，后端检索
- 评论系统：登录用户评论，盖楼回复，图形验证码防垃圾
- 分类与标签：文章分类（单选）和标签（多选）双维度管理
- 后台管理：登录认证、文章管理（Markdown 编辑器）、分类管理、标签管理、评论管理、博客设置
- 点赞：登录用户文章点赞，幂等操作
- 关于我：个人展示页，自由编辑
- 文章归档：按时间线分组展示历史文章
- 友情链接：后台管理友情链接
- RSS 订阅：提供 RSS/Atom Feed

### 功能调整
- 无（初始版本）

### AI增强调整
- 暂不引入 AI 增强功能（博主明确当前阶段优先完成核心功能）

### 非功能性需求
- 性能：首页加载 < 2s，详情页 < 1s，搜索 < 1s，支持缓存和 CDN
- 安全：密码 bcrypt 加密、图形验证码、防 XSS、防 SQL 注入、HTTPS
- 可用性：响应式设计、Markdown 实时预览、代码语法高亮
- 兼容性：Chrome/Firefox/Safari/Edge 最新版 + 移动端
