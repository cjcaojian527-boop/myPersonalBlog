# 产品需求文档 (Product Specification)

## 项目概述

**项目名称**：PersonalBlog

**一句话描述**：个人全栈技术博客系统，用于记录技术文章、展示全栈开发能力，作为简历亮点。

**目标**：打造一个完全自主可控、高自由度的个人技术博客，同时通过从零搭建的过程锻炼全栈开发与部署能力。

## 目标用户

**核心用户群体**：
- 博主本人（写作发布）
- 面试官/招聘方（浏览评估）

**用户特征**：
- 年龄段：20-40 岁
- 技术水平：技术开发者，熟悉 Web 技术
- 使用场景：日常撰写技术文章、管理博客内容；面试时作为作品展示
- 痛点：第三方平台（CSDN/掘金/知乎）限制多、不可控；需要一个完全归自己所有的技术博客来体现全栈能力

## 核心功能

### 功能 1：文章列表与详情

**功能描述**：博客的核心浏览功能，展示所有已发布文章，点击进入文章详情页阅读全文。

**输入**：
- 文章分类筛选（可选）：string，例如 "前端"
- 文章标签筛选（可选）：string，例如 "Vue"
- 排序方式（可选）：string，枚举值 "time"（按时间倒序，默认）/ "views"（按阅读量）/ "likes"（按点赞数）
- 分页页码：number，默认第 1 页

**输出**：
- 文章列表：Array，每项包含 {标题、摘要、发布时间、阅读量、分类标签}
- 文章详情：{标题、正文（Markdown 渲染后 HTML）、发布时间、阅读量、分类、标签列表、封面图（如有）、点赞数}
- 上一篇/下一篇导航链接
- 分页信息：{当前页、总页数、每页条数}

**业务规则**：
- 仅展示状态为"已发布"的文章，草稿不对外显示
- 默认按发布时间倒序排列，最新文章在最前
- 支持切换排序方式：时间倒序、阅读量倒序、点赞数倒序
- 文章列表每页显示条数由后台管理员设置
- 文章正文以 Markdown 格式编写，前端渲染为 HTML
- 正文中的代码块需要有语法高亮
- 文章可设置一张封面图，在详情页顶部展示
- 阅读量每访问一次详情页 +1
- 点赞仅登录用户可操作（在文章详情页底部），同一用户对同一文章只能点赞一次

**异常处理**：
- 文章不存在：返回 404 页面
- 列表为空：显示占位符提示"暂无文章"
- 封面图未设置：不显示封面区域
- Markdown 内容为空：显示"暂无内容"

**优先级**：高

**状态**：待开发

### 功能 2：搜索

**功能描述**：用户通过关键词快速检索文章，搜索结果以文章列表形式展示。

**输入**：
- 搜索关键词：string
- 搜索范围：标题 + 正文 + 标签
- 触发方式：按 Enter 键触发

**输出**：
- 搜索结果列表：格式与文章列表一致（标题、摘要、发布时间、阅读量、分类标签）
- 分页信息
- 无结果时显示提示文本

**业务规则**：
- 搜索范围覆盖标题、正文、标签
- 按 Enter 键触发搜索
- 搜索结果页布局与普通文章列表一致
- 需要后端实现全文检索或数据库模糊查询

**异常处理**：
- 关键词为空：不触发搜索，输入框保持聚焦
- 无匹配结果：显示"未找到相关内容"
- 搜索服务不可用：显示"搜索功能暂不可用，请稍后重试"

**优先级**：高

**状态**：待开发

---

### 功能 3：评论系统

**功能描述**：登录用户在文章详情页发表评论，支持盖楼回复，管理员可在后台管理评论。

**输入**：
- 评论内容：string（必填）
- 图形验证码：string（必填，每次提交需验证）
- 父级评论 ID（可选）：number，用于回复评论，实现盖楼

**输出**：
- 评论列表：Array，每项包含 {评论者昵称、头像、评论内容、时间、被回复者昵称（如有）}
- 评论总数

**业务规则**：
- 仅登录用户可发表评论
- 评论无需审核，发表后直接显示
- 支持回复评论（盖楼），显示回复层级关系
- 每次提交评论需要输入图形验证码，防垃圾评论
- 管理员可在后台删除评论
- 不支持评论通知（邮件/站内信）

**异常处理**：
- 未登录用户：显示"请先登录后再评论"
- 验证码错误：提示"验证码错误，请重新输入"
- 评论内容为空：提示"评论内容不能为空"
- 评论提交失败（网络异常）：提示"评论发表失败，请稍后重试"

**优先级**：中

**状态**：待开发

---

### 功能 4：分类与标签

**功能描述**：对文章进行分类和标签双维度管理，方便检索和归类。

**输入**：
- 分类名称：string（创建/编辑时）
- 标签名称：string（创建/编辑时）
- 文章分配：为文章选择分类和标签

**输出**：
- 分类列表：展示在导航栏和侧边栏
- 标签云：展示在侧边栏
- 分类文章列表：点击分类后展示该分类下所有文章

**业务规则**：
- 一篇文章只能属于一个分类，但可以拥有多个标签
- 分类可在后台管理（新增、编辑、删除）
- 标签在编写文章时动态添加，后台可管理
- 删除分类前需确认该分类下无文章或迁移文章到其他分类
- 分类显示顺序可在后台调整

**异常处理**：
- 分类下还有文章时删除：提示"该分类下还有 X 篇文章，请先迁移"
- 分类名称重复：提示"该分类已存在"

**优先级**：高

**状态**：待开发

---

### 功能 5：后台管理

**功能描述**：博主通过后台管理系统发布文章、管理内容、配置博客参数。

**包含子功能**：

**5.1 登录认证**
- 输入：用户名 + 密码
- 业务规则：账号密码登录（后续可扩展第三方登录）
- 异常处理：账号或密码错误提示"用户名或密码错误"

**5.2 文章管理**
- 输入：标题、正文（Markdown）、分类、标签、封面图、状态（草稿/已发布）
- 业务规则：支持 Markdown 编辑器 + 实时预览；草稿状态文章不对外显示；支持文章的增删改查
- 异常处理：标题为空时提示"标题不能为空"

**5.3 分类管理**
- 输入：分类名称、显示顺序
- 业务规则：增删改查分类，支持排序

**5.4 标签管理**
- 输入：标签名称
- 业务规则：增删改查标签

**5.5 评论管理**
- 输入：评论 ID
- 业务规则：查看所有评论列表，支持删除评论
- 异常处理：删除确认弹窗

**5.6 博客设置**
- 输入：每页文章显示条数
- 业务规则：管理员可配置分页参数

**异常处理**：
- 未登录直接访问后台：跳转到登录页
- Token 过期：跳转到登录页，提示"登录已过期，请重新登录"

**优先级**：高

**状态**：待开发

---

### 功能 6：点赞

**功能描述**：登录用户在文章详情页点赞，表达对文章的认可。

**输入**：
- 文章 ID：number
- 用户 ID：number（由登录态携带）

**输出**：
- 点赞总数更新
- 按钮状态变更（已点赞/未点赞）

**业务规则**：
- 仅登录用户可点赞
- 同一用户对同一文章只能点赞一次
- 点赞按钮位于文章详情页底部

**异常处理**：
- 未登录用户点击：提示"请先登录"
- 重复点赞：不增加计数（幂等操作）

**优先级**：中

**状态**：待开发

## 功能优先级

### 高优先级（必须有）
1. 文章列表与详情 - 博客的最基础功能，没有它博客不存在
2. 搜索 - 检索功能是内容型网站的必备能力
3. 分类与标签 - 内容组织和导航的基础
4. 后台管理 - 博主生产内容和管理博客的入口

### 中优先级（应该有）
1. 评论系统 - 加强互动，面试时展示完整用户交互能力
2. 点赞 - 轻量级互动功能
3. 关于我 - 个人展示页，面试时直接体现个人品牌
4. 文章归档 - 提升浏览体验

### 低优先级（可以有）
1. 友情链接 - 锦上添花
2. RSS 订阅 - 技术博客的标配，但非紧急

## AI增强功能

本次版本暂不引入 AI 增强功能。理由：博主明确表示当前阶段先不考虑 AI，专注完成核心博客功能。后续迭代中可引入 AI 摘要生成、智能标签推荐等功能。

## 非功能性需求

### 性能要求
- 首页加载时间 < 2 秒
- 文章详情页加载 < 1 秒
- 搜索响应时间 < 1 秒
- 支持静态资源缓存和 CDN

### 安全要求
- 登录认证：账号密码登录，密码加密存储（bcrypt）
- 图形验证码：评论提交时验证
- 防 XSS：用户输入内容转义处理
- 防 SQL 注入：使用 ORM 参数化查询
- HTTPS 部署

### 可用性要求
- 响应式设计，适配桌面和移动端
- 后台 Markdown 编辑器提供实时预览
- 代码块语法高亮，支持多种编程语言

### 兼容性要求
- 支持 Chrome、Firefox、Safari、Edge 最新版本
- 移动端兼容 iOS Safari 和 Android Chrome

## 技术栈建议

待 /dev 阶段由全栈开发工程师根据博主偏好确定。预期方向：
- 前端：现代前端框架（React/Vue/Next.js/Nuxt.js）
- 后端：Node.js / Go / Python 可选
- 数据库：关系型数据库（MySQL/PostgreSQL）
- 部署：云服务器 + Nginx + HTTPS

## 附录

### 术语表
- **盖楼**：评论的嵌套回复形式，A 评论下 B 回复，B 下 C 再回复，形成层级结构
- **Markdown**：轻量级标记语言，用于编写格式化文档
- **RSS**：Really Simple Syndication，内容聚合订阅协议
